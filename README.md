# Repositorio_IFTM

Este repositório contém materiais, projetos e anotações desenvolvidos durante o curso de Sistemas para Internet.
É um espaço destinado ao estudo e prática dos conteúdos aprendidos.

## 📚 Conteúdo

* [Algoritmos](./Algoritmos) - Estudo de Algoritmos. Consulte [beecrowd](https://judge.beecrowd.com/pt/profile/1116315) para ver o perfil com as resoluções.
* [BancoDeDados](./BancoDeDados) — Estudo da modelagem de banco de dados e utilização da linguagem SQL.
* [FundamentosSI](./FundamentosSI) — Estudo de Redes e base do curso.
* [IHC](./IHC) — Projetos e estudos focados em Interação Humano-Computador.
* [JavaScript](./Javascript) - Aplicações em JavaScript com HTML e CSS.
* [LogicaDeProgramacao](./LogicaDeProgramacao) - Apenas um projeto final. Consulte [beecrowd](https://judge.beecrowd.com/pt/profile/1116315) para ver o perfil com as resoluções.
* [NoSql](./NoSql) — Materiais, resumos e estudos sobre bancos de dados não relacionais.
* [POO](./POO) - Estudo de Programação Orientada a Objetos com Java.
* [ProjetoBackEndMicrosservicos](./ProjetoBackEndMicrosservicos) — Aplicações e práticas focadas em arquitetura de microsserviços.
* [ProjetoBackEndMonolítico](./ProjetoBackEndMonolítico) — Projetos de back-end desenvolvidos em arquitetura monolítica.
* [ProjetoFrontEndWeb](./ProjetoFrontEndWeb) — Desenvolvimento e interfaces de front-end para web.
* [ProjetoMVC](./ProjetoMVC) — Aplicações desenvolvidas utilizando o padrão de arquitetura MVC (Model-View-Controller).
* [ProjetoWebsiteEstatico](./ProjetoWebsiteEstatico) — Projeto de site estático desenvolvido em HTML/CSS.
* [SistemasDistribuidos](./SistemasDistribuidos) — Exercícios e projetos práticos sobre sistemas distribuídos.
* [TestesAutomatizados](./TestesAutomatizados) — Implementação de testes automatizados e de integração.
